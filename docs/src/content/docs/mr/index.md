वाहन नोंदणी हाताळणाऱ्या डीलरशिप डेस्कसाठी मोफत Windows अ‍ॅप. OEM
सिस्टीमची टॅक्स इन्व्हॉइस PDF उघडा, अ‍ॅप सूट लाइन काढून GST आकडे आणि
शब्दांतील रक्कम पुन्हा लिहून देईल — जेणेकरून RTO कॉपीवर आकारी बरोबर
बसेल.

- **स्थानिक आधी.** इन्व्हॉइस तुमच्या संगणकाबाहेर जात नाहीत. अ‍ॅप
  इंटरनेटचा वापर फक्त अपडेट तपासण्यासाठी करते.
- **प्रत्येक इन्व्हॉइसला दोन मिनिटे.** PDF टाका, दुरुस्त कॉपी मूळ फाईलीसोबत
  सेव्ह करा.
- **एका डीलरशिप डेस्कसाठी बनवलेले.** ना खाती, ना सर्व्हर, ना सदस्यता.
